# Deterministic Layout Rules

- Grid: 10 px.
- Standard node: 160×70.
- Horizontal gap: 80 px; 120 px with edge labels.
- Vertical gap: 60 px; 90 px between independent branches.
- Container padding: 30 px sides/bottom, 45 px below title.
- Major group gap: 80 px.
- Outer canvas margin: 40 px.

Place externals, entry points, processing, data stores, downstream systems, then support services. Keep optional/error paths outside the primary corridor.
