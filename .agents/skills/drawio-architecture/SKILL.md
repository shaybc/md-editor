# Draw.io Architecture Skill

Use `drawio-core` first.

1. Determine context, container, component, deployment, data-flow, or mixed overview.
2. Do not mix more than two abstraction levels per page.
3. Classify actors, clients, edge/API, services, messaging, data, externals, and operations.
4. Default to left-to-right.
5. Use real boundaries only: domain, VPC, cluster, namespace, trust zone, or application.
6. Put shared infrastructure where total crossings are lowest.
7. Separate synchronous and asynchronous corridors.
8. Avoid full meshes; introduce only semantically real gateways, brokers, or buses.
