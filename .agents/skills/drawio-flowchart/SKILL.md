# Draw.io Flowchart Skill

Use `drawio-core` first.

1. Identify start, end, actions, decisions, loops, and ownership.
2. Default top-to-bottom; use left-to-right for pipelines.
3. Keep the happy path straight.
4. Put failures and exceptions consistently on one side.
5. Merge branches through explicit merge nodes.
6. Route loop-backs on the outer perimeter.
7. Use swimlanes only when ownership or handoff matters.
