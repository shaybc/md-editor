# 7. Keyboard Shortcuts

Keyboard shortcuts keep frequent actions close to your hands. They are especially useful when editing large documents, searching a project, or switching between writing and review.

## General

| Action | Shortcut |
| --- | --- |
| New document | <kbd>Ctrl</kbd> + <kbd>T</kbd> |
| Save active file | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| Reload active file | <kbd>Ctrl</kbd> + <kbd>R</kbd> |
| Toggle full screen | <kbd>F11</kbd> |
| Open downloads | <kbd>Ctrl</kbd> + <kbd>J</kbd> |
| Zoom in | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>=</kbd> |
| Zoom out | <kbd>Ctrl</kbd> + <kbd>-</kbd> |
| Actual size | <kbd>Ctrl</kbd> + <kbd>0</kbd> |

## Search

| Action | Shortcut |
| --- | --- |
| Find in active file | <kbd>Ctrl</kbd> + <kbd>F</kbd> |
| Find / Replace | <kbd>Ctrl</kbd> + <kbd>H</kbd> |
| Find in Workspace | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> |
| Open File by Name | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| Find in Files | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> |
| Show / Hide Find in Files results | <kbd>F7</kbd> |
| Show / Hide Problems | <kbd>F8</kbd> |
| Rebuild Project | <kbd>Ctrl</kbd> + <kbd>F9</kbd> |

Business benefit: search shortcuts are often faster than folder navigation. Use them when the folder is large or when you remember content better than location.

## Editing

| Action | Shortcut |
| --- | --- |
| Duplicate line | <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Undo | Standard system shortcut |
| Redo | Standard system shortcut |
| Cut / Copy / Paste | Standard system shortcuts |
| Select all | Standard system shortcut |

The editor menu also includes indentation, case conversion, comment/uncomment, trailing-space trimming, leading-space trimming, tab-to-space conversion, and space-to-tab conversion.

## Navigation Tips

- Use <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> to jump to a file when the folder tree is too large to browse manually.
- Use <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> to find a concept across the current workspace.
- Use <kbd>F7</kbd> to keep results visible while you edit.
- Use <kbd>F11</kbd> when presenting or reviewing long documents.
