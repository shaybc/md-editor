# Index

Welcome. MD-Editor helps you keep local Markdown documents, project notes, generated code maps, and graph views in one desktop workspace. The app is designed for daily technical writing: open a folder, edit files in tabs, preview rich Markdown, inspect relationships in Graph View, and export the result without leaving the desktop app.

This manual is organized like the app itself. Start with the essentials if you are new, then move into files, editing, graph work, tools, settings, and shortcuts as you need them.

## Quick Start

1. Choose <kbd>Actions</kbd> -> <kbd>Open folder...</kbd> and select a local documentation or source folder.
2. Click a Markdown file in the folder tree to open it in a tab.
3. Use <kbd>Editor</kbd>, <kbd>Split</kbd>, or <kbd>Preview</kbd> in the header to choose how much rendered output you want to see.
4. Use <kbd>Ctrl</kbd> + <kbd>S</kbd> to save the active file.
5. Open Graph View when you want to inspect links, tags, generated dependency maps, or saved graph documents.

> Tip: If you are exploring a large repository, start by opening the folder, then use <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> to open a file by name instead of manually expanding every folder.
