---
id: investigate-defect
name: Investigate a Defect
description: Evidence-led debugging from symptom to root cause.
triggers: [bug, broken, error, not working]
allowedModes: [plan, agent]
---
Reproduce or precisely restate the symptom. Trace the input, state changes, and output across the smallest relevant path. Use each observation to eliminate alternatives. Stop before implementing unless the user requested a fix, and label conclusions by evidence strength.
