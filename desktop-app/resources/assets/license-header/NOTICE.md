# Offline license header references

The canonical license texts and descriptive metadata in this directory were
derived from the GitHub-maintained `github/choosealicense.com` repository at
commit `d6277c04899ce98b13d713186b48d110ac998d0b`.

Source: https://github.com/github/choosealicense.com

The upstream repository is distributed under the MIT License. Each canonical
license text describes its own licensing terms. MD-Editor stores these files
locally for offline identification. Matching remains exact outside the upstream
template fields `[year]`, `[yyyy]`, `[fullname]`, and
`[name of copyright owner]`; completed placeholder values must stay on one line.

The upstream YAML front matter is not bundled with the canonical text files.
Descriptions were shortened for the MD-Editor interface, while permission,
condition, and limitation classifications follow the pinned upstream metadata.
