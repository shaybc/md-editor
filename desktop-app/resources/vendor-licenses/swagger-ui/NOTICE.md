# Swagger UI

MD-Editor vendors the browser-ready Swagger UI assets from the `swagger-ui-dist` npm package.

- Package: `swagger-ui-dist`
- Version: `5.32.14`
- License: Apache-2.0
- Source: https://github.com/swagger-api/swagger-ui

The runtime assets are copied into `resources/vendor/swagger-ui/` by `desktop-app/download-vendor.js`.
